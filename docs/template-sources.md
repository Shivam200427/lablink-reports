# Template wording sources (server/templates.js)

Every per-test template was drafted as factual, hedged, non-diagnostic
patient-education text and verified 2026-11-02 against the MedlinePlus
lab-test pages below ("What do the results mean?" sections). Each cause a
template names for a high or low value appears in, or follows directly from,
the cited page. Where a direction has no well-sourced meaning (for example a
low liver-enzyme value), the template states only the test's purpose and that
the value is outside the lab's reference range - no blanket reassurance.

Not clinically reviewed; Telugu/Hindi drafts need a fluent reviewer. The
appended per-summary line always defers to the doctor.
